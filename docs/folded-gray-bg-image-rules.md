# 灰底折叠展示图 · 生图指令规范（2026-10-24 用户定）

适用：单独被套（duvet cover）等床品的「灰底叠放展示图」。与种草图（`lifestyle-image-rules.md`）不同，本类图为摄影棚灰底产品图，无场景无道具。

- 模型：火山方舟 seedream 5.0 pro（`doubao-seedream-5-0-pro-260628`），同步 API `/api/v3/images/generations`
- 参数：`size: "1440x1920"`（3:4）、`watermark: false`、`response_format: "url"`
- 参考图：对应产品主图（如 `public/images/products/<ASIN>/1-3x4.webp`），sharp 压到 1024px 内、jpg q85，base64 传入 `image` 字段；仅作布料来源
- 参考脚本：`scripts/seedream-sage-duvetonly-stacked.js`、`scripts/seedream-percalejac-oatbeige-duvetonly-stacked.js`

## 构图尺寸基准（按用户确认的 sage 参考图实测，1440×1920）

| 项 | 占比 |
| --- | --- |
| 产品总高度（含翻角） | 画面高度的 **40%–45%**（约 43%） |
| 产品宽度 | 画面宽度的 **80%–85%** |
| 水平位置 | 居中 |
| 产品底边位置 | 画面高度的约 **80%** 处 |
| 上方留白 | 约 35%–38% |
| 下方留白 | 约 15%–20% |

每次生成必须在 prompt 中明确写出产品高度占比，不得只写"占画面主体"。

## Prompt 模板（替换 {{ }} 占位符后使用）

```
一条 duvet cover（被套）按真实物理方式折叠：先平铺，上下对折一次，再左右对折一次，形成规整长方形，共 4 层布料。正前方略带俯视的拍摄角度。

构图与占图比例（必须严格遵守）：产品水平居中，产品总高度（含顶部翻角）约占画面高度的 43%（允许 40%-45%），产品宽度约占画面宽度的 82%；产品底边位于画面高度约 80% 处，上方留白约 37%，下方留白约 17%；不要顶天立地，不要把产品撑满画面。

折叠结构必须严格符合几何逻辑：1. 前缘为被套的自由边（开口侧），可见 4 层布边整齐平行叠放，每层厚度均匀、间距一致；2. 左右两侧为对折形成的折痕边（封闭的圆弧折边），折痕方向与对折方式一致，侧面层数与前缘层数必须吻合，不得出现多余卷边、螺旋或不属于这条被套的独立布卷；3. 被套外沿只有翻起露背面的那一处开口，其余边缘平整服帖，无散开的布料。

翻角方式（关键）：仅把最上层布料远离镜头那一侧的一个角，沿一条对角折线向前翻折，翻折后搭在顶面上；翻起部分与顶面布料沿折线完全连续、是一整块布，绝不是单独放上去的另一块布；翻起部分露出的纯色背面，与顶面正面是同一块布的正反两面，在折线处能看到正面与纯色背面沿同一条折线自然过渡。翻角后顶面剩余部分仍保持平整矩形，不塌陷、不鼓起。背面为{{B面描述，如：与正面同色系的纯色鼠尾草绿（sage green）棉质面料}}，无任何图案。

背景为干净的浅灰色纯色摄影背景，柔和自然光，被套底部有浅浅的投影。

被套正面布料严格取自参考图：{{正面布料描述，含颜色、图案、织纹、质感，如：燕麦米白与米白色相间的宽竖条纹提花棉质面料，带明显华夫格织纹肌理、哑光柔和质感}}；条纹/图案宽度比例、配色密度与参考图 1:1 对应，严禁色偏、严禁加宽或改动图案。所有条纹严格平行、笔直、间距均匀，从顶面到前缘各折叠层逐条对齐连续，折叠转折处条纹沿布面自然弯曲，无错位、无断裂、无重影、无涂抹感。（非条纹产品保留"图案自然连续"要求即可）

参考图仅作布料来源，严禁沿用其卧室场景与任何陈设。写实摄影质感，画面无文字、无水印、无logo、无人、无道具、无其他床上用品。
```

## 验收清单

- 产品高度占比约 40%–45%，底边约 80% 位置，上方留白充足
- 布料颜色/图案与主图一致，无色偏、无比例改动
- 折叠逻辑：前缘自由边层数与侧面折痕一致，无独立布卷；翻角与顶面连续、露 B 面纯色
- 条纹/图案跨层对齐，无错位断裂
- 灰底干净、无文字水印道具
