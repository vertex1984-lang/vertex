# 种草图生成规则（Lifestyle / Mood Image Prompt Standard）

> 2026-10-13 用户定。以后用户说"种草图"，一律按本文档的六段式指令级别出图，不得降级为一句话场景描述。
> 用途：Pinterest / INS 种草晒图、PDP 种草双图区、首页图流——需要快速抓住注意力、博取流量，场景要丰富、风格要鲜明。

## 一、品牌风格锚点（每张图必须命中）

- 色调：米色 `#F8F5F0` + 暖棕 `#8B5A2B` 品牌调性，奶油暖色系，低饱和，prompt 中必须注明。
- 氛围：温暖、舒适、松弛（lived-in、不刻意摆拍），ins 生活方式杂志感。
- 画风：ins 奶油风 / 原木风为基底，可混中世纪复古、侘寂元素制造记忆点。
- 硬性禁忌：无文字、无水印、无 logo、布面零织标零印花；品牌 Logo/吉祥物不让 AI 画。

## 二、六段式指令结构（按此顺序拼接）

### 1. 产品锚定段（img2img 必写）
精准锁定参考图产品的：布料材质肌理（逐项描述，如"泰迪绒卷圈绒颗粒感卷毛肌理、蓬松柔软哑光雾面"）、颜色（中英文双写，1:1 不变）、造型尺寸比例原样复刻、布面零织标零印花。
**混色规则（2026-10-13 用户定）**：一组两个产品时用混色搭配，不要两个同色——每张参考图锁定一个颜色，prompt 里注明"参考图1=颜色A、参考图2=颜色B，颜色分别与参考图 1:1 对应"，低饱和撞色制造视觉焦点（如奶白+鼠尾草绿、燕麦+灰粉）。
若是场景复刻类任务（参考图是整个房间），改为：精准锁定原图全部空间布局、相机透视角度、家具摆件绿植灯具位置 1:1 复刻，零增减/移位/缩放。

### 2. 场景构建段（复杂、丰富、有叙事）
- 场景物品种类 ≥ 8 样：主体家具、主角产品（2 个一正一斜/前后错开为视觉焦点）、搭毯、茶几/边几、杯饮（拿铁带拉花/茶）、读物（翻开的杂志/布面书）、香薰蜡烛/托盘、绿植（大型琴叶榕/吊钟/尤加利/干花芦苇，带自然脉络绒面质感）、地毯、灯具、挂画。
- 每样物品带材质描述：天然洞石带孔隙纹理、粗陶、原木带木纹年轮、羊毛几何编织长毛毯、黄铜、藤编、亚麻自然褶皱。
- 构图有前景/中景/远景层次，有呼吸感留白。

### 3. 光线氛围段
温暖金色时刻自然日光，透过百叶窗/白纱帘漫射入室，地面与家具形成柔和斑驳光影，柔和漫射渐变阴影，窗边日光自带温润光晕，自然光线衰减，暖色温。

### 4. 镜头画质段
专业室内家居摄影，8K 超高清，浅景深电影镜头效果（焦点锁定产品，前景与背景自然虚化），细微复古胶片颗粒，轻微镜头边缘柔化，超写实真实物理材质。

### 5. 品牌调性段（二选一）
- 站内图（PDP 双图区/首页）：整体暖色温奶油色调，米色 #F8F5F0 + 暖棕 #8B5A2B 品牌调性，低饱和 ins 风。
- 社媒种草图（Pinterest/INS 引流，2026-10-13 用户定）：**不绑网站色系**——ins 生活方式博主实拍感，自然真实色彩还原，白平衡准确，清爽通透不发闷，色彩饱和自然不刻意暖调，像真实博主家里的随手拍大片。

### 6. 负向规避段（原样使用）
零改动产品颜色质感；规避塑料 CGI 质感、光滑假表面、平涂死黑阴影、高饱和色彩、卡通插画画风、失真反光、扭曲透视、任何文字水印 logo。

## 三、API 参数

| 参数 | 值 |
|---|---|
| aiTypeId / aiType | `113` / `smartImg` |
| mode | `gpt-image-2.5-sunburst`（高质，AGENTS.md 默认） |
| size | `2K` |
| imgRatio | Pinterest 用 `2:3`（竖图，输出 1200×1800）；INS feed 用 `4:5`；PDP 双图区/首页用 `4:3`（输出 1600×1200）。API 不支持时回退 `4:3` |
| inputImgs | 产品灰底主图线上 URL（img2img 保质感） |
| 输出 | sharp → webp q82，存入 `public/images/` 对应目录 |

生成后必须 ReadMediaFile 验收（材质是否保住、颜色是否漂移、有无文字/标签），再给用户确认；确认后才接入页面并推送。
