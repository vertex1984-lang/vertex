# 产品主图生成规则（Product Main Image Template）

> 2026-10-31 用户定方向，综合竞品分析（Parachute 货架纪律 / Urban Outfitters 机位签名）后定版。
> 与 `lifestyle-image-rules.md`（种草图）分工：**主图负责"统一辨识度 + 颜色花型辨认"，种草图负责"丰富场景引流"**。
> 状态：**已定稿**——机位档位经 3 张样图对比后由用户锁定为 C（55° 高机位半俯视），见文末试验记录。

## 一、构图签名模板（最高优先级）

一句话规格：**"晨光斜射 + 55° 高机位纵向俯拍 + 半整理床铺"**。

- 机位：固定 55° 高机位**纵向俯拍**——相机在床尾右上方高处，沿床身长度朝床头俯拍，接近垂直俯视床面。枕头俯视见完整枕面，床头板几乎不入画（最多顶部露一条边），看不到墙面/窗户/壁灯。比 UO 正俯拍有人居感，比平视更能在手机小图上展示被面/枕面。**定死一个值，不给范围**（AI 出图给范围=每张角度都飘）。
- **对角线方向锁定**：床头板在画面左上方、床尾在右下方，床身从左上向右下对角延伸——全系列同向、不得镜像（2026-10-31 sand 批次实测被参考图镜像带偏，prompt 必须显式写方向）。
- **被面 + 枕面（产品有效面积）≥ 75%**，是绝对主体；画面底部可见一小条地板。
- ⚠️ img2img 时参考图会带偏构图：prompt 必须显式写"忽略参考图的构图和机位，仅参考床品颜色和图案"（2026-10-31 v1 批次实测翻车，角度被参考图拉回平视）。
- 褶皱程度统一为"半整理"：有生活感、不刻意，但能看清面料垂坠。太平整像产品图，太乱像抓拍。
- 固定裁切比例：3:4（与产品卡一致，不做二次裁切）。

## 二、色温与色准分层

- 白平衡中性，统一 LUT 校色；**白色床品必须读得出"白"**，同一颜色在所有主图中色相一致。
- 暖调只允许来自：① 晨光方向（侧向低角度自然光）② 暖色道具材质（原木、藤编、亚麻、燕麦色织物）。
- **禁止整体偏黄**——暖黄"长在规则里"，不"飘在每张图里"。

## 三、图序分层（主图 + 副图职责分离）

| 位置 | 内容 | 职责 |
|---|---|---|
| 列表页主图 | 本模板暖光场景图 | 辨识度 + 点击率（颜色/花型可辨即可，不承担细节展示） |
| 列表页 hover 第二张 | 中性底平铺图 | 快速对比颜色，不用进 PDP |
| PDP 第 2-3 张 | 中性底纯产品平铺图 | 颜色与材质判断（借 Parachute） |
| PDP 第 4 张 | 织纹特写 | 面料质感确认 |

细节确认永远交给副图——手机卡 ~185px 宽度下，任何构图都传达不了织纹，主图不背这个任务。

## 四、道具站位公式（物件可换，角色和站位不变）

- 绿植 ×1：固定在画面某一角
- ❌ 不要有毯子（2026-11-01 用户定）：床上/床尾不出现针织毯、盖毯、毛毯——床品本身是唯一主体
- 书 / 咖啡 ×1：固定在一侧床头柜
- 床头：浅原木或浅色软包（1-2 种固定下来，不漂移）
- 具体物件每张可换，站位不变（UO 用杂志/地毯/拖鞋做到的事）

## 五、验收标准

生成后缩到 **185px 宽**（手机双列卡实际尺寸）验收：能辨认颜色倾向和花型、画面不空 → 达标；看不出颜色 → 取景太松，收紧重出。

## 六、生成参数

- 模型：seedream 5.0 pro（`doubao-seedream-5-0-pro-260628`，备用账号 `scripts/.ark-api-key-2`），img2img 锁产品颜色材质
- 尺寸：3:4（`1536x2048`；`1872x2496` 超 API 面积上限不可用）
- 批量脚本：`scripts/seedream-main-c-batch.js`；样图脚本：`scripts/seedream-main-template-test.js`

## 七、试验记录

- 2026-10-31：PERCALE-COCONUT-QUEEN（纯色椰白，最易生成）出 3 档对比：A=35° 紧取景 / B=35° 标准（床 65%）/ C=55° 高机位半俯视。**用户定档 C**——高机位下被面/枕面有效面积最大，手机端小图辨识度最好。
- 2026-10-31：按 C 方案生成首批 2 张图案款：WASHSTRIPE-SAGEGREEN-QUEEN（水洗棉细条纹灰绿）、PERCALECHECK-SAND-QUEEN（贡缎细格纹沙色）。规则图案需重点验收条纹/格纹是否扭曲变形。
- 2026-10-31：v1 批次机位翻车（被参考图构图拉回平视），机位段升级为 v2（显式纵向俯拍 + "忽略参考图构图"硬约束）后重出，两张均通过验收。
- 2026-10-31：PERCALEJAC-HAZE-QUEEN（雾蓝/奶白宽条纹提花贡缎）按 v2 模板生成。
- 2026-10-31：PERCALECHECK-SAND-QUEEN 换 alicdn 实物参考图重出（花纹实际是极细密白线条，非稀疏大格）；v3 机位段增加对角线方向锁定。
- 2026-10-31：**Sheets & Duvet Sets 全类目（/bedding/4-piece-sets/ 共 23 个家族卡）统一接入 C 方案**：每变体组取卡面代表 1 张，20 张新出/复用 + 首批 3 张；接入方式 = 切 `0-main-3x4.webp`（1200×1600 q82）+ `PDP_MAIN_PREPEND_IMAGES` 前置 + `featuredImage` 换卡面。脚本：`cut-main-c-to-products.js`、`patch-main-c-featured.js`。
